# Fonts

`manrope-latin-wght-normal.woff2` is the Latin subset of the variable font Manrope (weights 200 to 800), from the
`@fontsource-variable/manrope` package, version 5.2.5. Manrope is licensed under the SIL Open Font License 1.1
(see `OFL.txt`).

It is bundled here instead of downloaded from Google Fonts at build time, because that download failed the web
build intermittently (Milestone 28, row 7). To update it, download the same file from a newer package version.
