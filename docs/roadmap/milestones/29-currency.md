# Milestone 29: Hotel currency and display conversion

Status: **Opened 2026-10-25; owner-authorized Task 6 added 2026-10-28.** Code evidence is recorded per row; Task 6 is released and verified on Empire (2026-10-28). Other rows retain their recorded verification limits. **Gates the cutover:** the currency converter is required for the redesigned website.

## Goal

Each hotel has one **money currency**: bookings, payments and refunds always use it. Other currencies are **display only**: the same price shown as an approximate conversion, labelled as such, never charged.

## Decisions (owner, 2026-10-25)

- The property owner selects the hotel's default currency in the property settings. A hotel connected to a PMS takes the currency from the PMS rate it books (Clock reports a currency per rate: EUR for Website rates, ALL for Reception on Empire; no account-wide currency field is known), and the property setting is the fallback and the value shown to staff.
- The guest pays in the hotel's currency. Display currencies are chosen per property (for example EUR, USD, GBP, ALL).
- **Updated owner decision 2026-10-28:** hotel-managed rates win per currency, with the existing daily feed as fallback; conversion remains approximate/display-only. The hotel selects its display currencies in Settings. [ADR-0038](../../decisions/ADR-0038-hotel-display-exchange-rates.md) records storage direction, the pull contract and payment annotations.

- Empire: guests on the website see ALL, EUR, GBP and USD. The converter is an **Elementor widget** placed in the site header on the right side, to the left of the header button widget (element f01df27), so the owner can choose the display currencies and the default in Elementor.
- Historical 2026-10-25 assumption: Empire money currency EUR. Owner correction 2026-10-28: its default currency is ALL; the returned API base is authoritative for the converter. Task 6 release verification confirmed API and WordPress base ALL on 2026-10-28.
- The rate feed is fetched once a day and cached; the source must be free and include the lek.

**Live 2026-10-25:** WordPress plugin 0.4.110 is installed on Empire (room card price and facts, checkout rate picker inert until the new API, Elementor Currency Switcher widget). Until the platform API serves rates, the plugin reads the free daily euro feed directly (base EUR, prices on the site are EUR); the widget still has to be placed in the header in Elementor by the owner. At cutover the plugin uses the platform endpoint automatically.

## Findings

- The ECB euro reference rates cover 29 currencies and **do not include the Albanian lek (ALL)** (checked 2026-10-25 on the ECB page).
- The Bank of Albania publishes the official lek fixing on its own site; no official machine-readable feed was found. A third party (AllRatesToday) resells it as JSON with an API key. Task 1 records the selected free fallback feeds.
